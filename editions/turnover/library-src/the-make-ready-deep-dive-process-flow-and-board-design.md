# The Make Ready Deep Dive Process Flow and Board Design

## The Make Ready Deep Dive
Process Flow + Board Design for 420 Doors (Class B to D), [Company Name]
Two parts. Part 1 is the make ready process step by step: seven steps from scope lock to marketing handoff, plus the punch list loop, the scope change protocol, and the dispatch decision matrix in make ready context. Part 2 is the make ready board that runs it: 12 stages, the card columns, class-based time targets, automations, and the coordinator and leadership views. Built to be consistent with the Turnover Tracking Board, the Make-Ready Checklist, the Dispatch Decision Matrix, and the class benchmarks.
### Part 1: The Make Ready Process, Step by Step

---
Trigger: move-out inspection is complete AND scope is approved (or approved within threshold). The unit clock starts NOW.
#### Step 1: Scope Lock and Work Order Creation
Owner: Remote Coordinator
Gate (what must be true before this starts): (a) Move-out inspection report is uploaded with photos; (b) scope is either within the owner's pre-approved reserve threshold, then auto-approved, or the owner has responded with written approval

| # | Action |
|---|---|
| 1 | Coordinator reviews the inspection report and categorizes scope into: Cleaning / Repairs / Upgrades |
| 2 | Creates individual work orders in PM software for each task with deadline, scope of work, and access instructions |
| 3 | Assigns each work order to In-House Tech or Vendor per the Dispatch Decision Matrix (see below) |
| 4 | Logs target completion date based on class benchmark |

Handoff: Coordinator to In-House Tech (for standard repairs) AND/OR Vendor (for specialty work) + Cleaning Crew
#### Step 2: Scheduling and Access Confirmation
Owner: Remote Coordinator
Gate (what must be true before this starts): All work orders created and assigned

| # | Action |
|---|---|
| 1 | Confirms scheduled start date with each assignee |
| 2 | Confirms lockbox code or key access is active |
| 3 | Schedules cleaning crew (always runs parallel or immediately after repairs) |
| 4 | Schedules carpet cleaning if applicable |
| 5 | Schedules lawn care if applicable |
| 6 | Logs all scheduled dates on the board |

Handoff: Coordinator to all assigned parties; each receives written scope + access + deadline
#### Step 3: Work in Progress (Repairs)
Owner: In-House Tech / Vendor
Gate (what must be true before this starts): Access confirmed, work orders issued, materials sourced

| # | Action |
|---|---|
| 1 | Tech/Vendor executes scope per work order |
| 2 | Uploads progress photos to PM system at midpoint (Day 2 to 3 for a 5-day job) |
| 3 | Flags any hidden or discovered scope immediately to Coordinator (see Scope Change Protocol below) |
| 4 | Coordinator checks in daily (see Coordinator Daily Checklist in Part 2) |

Handoff: Tech/Vendor to Coordinator (completion notification + photos uploaded)
#### Step 4: Cleaning
Owner: Vendor (Cleaning Crew)
Gate (what must be true before this starts): All repair work orders marked complete; unit is clear of debris and materials

| # | Action |
|---|---|
| 1 | Deep clean all surfaces, appliances, fixtures |
| 2 | Carpet shampoo (if applicable) |
| 3 | Sanitize bathrooms and kitchen |
| 4 | Lawn care completed (exterior) |
| 5 | Coordinator confirms cleaning is scheduled same day repairs close |

Handoff: Cleaning Vendor to Coordinator (completion confirmation + photos)
#### Step 5: Pre-Final Coordinator Review
Owner: Remote Coordinator
Gate (what must be true before this starts): All work orders marked complete, cleaning confirmed done

| # | Action |
|---|---|
| 1 | Coordinator does a digital review of all uploaded photos against the original scope checklist |
| 2 | Confirms every line item on the Make Ready Checklist is addressed |
| 3 | If anything is missing, sends it back to Tech/Vendor before scheduling final inspection |
| 4 | If clean, schedules final inspection |

Handoff: Coordinator to Inspector (In-House Tech or designated PM)
#### Step 6: Final Inspection
Owner: In-House Tech (senior) or PM / Coordinator (if on-site capable)
Gate (what must be true before this starts): Pre-final review passed, all work orders closed, cleaning done

| # | Action |
|---|---|
| 1 | Walk the unit against the Final Inspection Checklist (below) |
| 2 | Upload inspection report + photos to PM system |
| 3 | Record one of two outcomes: PASS moves to Step 7; FAIL enters the Punch List Loop (see below) |

Handoff: Inspector to Coordinator (pass/fail + report)
Final Inspection Checklist:

| Item | Result |
|---|---|
| All reported issues from move-out resolved | ☐ Pass   ☐ Fail |
| Appliances tested | ☐ Pass   ☐ Fail |
| Plumbing flushed and checked | ☐ Pass   ☐ Fail |
| HVAC filter replaced, system tested | ☐ Pass   ☐ Fail |
| Smoke/CO detectors tested | ☐ Pass   ☐ Fail |
| Locks rekeyed | ☐ Pass   ☐ Fail |
| Windows/screens functional | ☐ Pass   ☐ Fail |
| Unit clean to standard | ☐ Pass   ☐ Fail |

#### Step 7: Photography and Marketing Handoff
Owner: Coordinator (schedules) / Photographer (executes)
Gate (what must be true before this starts): Final inspection PASSED

| # | Action |
|---|---|
| 1 | Coordinator schedules photographer (within 24 hours of pass) |
| 2 | Photos taken and uploaded |
| 3 | Coordinator confirms photos are live-ready |
| 4 | Coordinator notifies Leasing Team: "Unit is photo-ready and available for listing" |
| 5 | Coordinator notifies Owner: "Make ready is complete. Unit is rent-ready." |
| 6 | Board card moves to Make Ready Complete |

Handoff: Coordinator to Leasing Team (full handoff, unit exits the make ready board)
#### Punch List Loop (Failed Final Inspection)
When the final inspection fails:

| # | What Happens |
|---|---|
| 1 | Inspector documents every failed item with photos; Punch List created |
| 2 | Board card moves back to the "Punch List / Rework" stage (it does NOT go back to Step 1) |
| 3 | Coordinator reviews the punch list within 2 hours of receiving it |
| 4 | Each punch list item is assigned back to the responsible party (original Tech or Vendor) |
| 5 | Deadline set: 24 to 48 hours depending on class (Class D gets 48 hours, Class B gets 24 hours) |
| 6 | Responsible party completes punch list items, uploads photos |
| 7 | Re-inspection scheduled (same inspector if possible) |
| 8 | If the unit fails twice, it escalates to Operations Lead / PM Director for review before a third inspection |

Clock continues running: days in Punch List count against the class benchmark.
#### Scope Change Protocol (Discovered Mid-Job)
When a Tech or Vendor discovers work not in the original scope:

| Scenario | Action |
|---|---|
| Under $X threshold (owner's pre-approved reserve) | Coordinator approves immediately, creates new work order, updates board |
| Over threshold but under $500 above | Coordinator calls owner directly; verbal approval + email confirmation required within 2 hours |
| Over threshold by $500+ | Coordinator sends formal bid/estimate to owner via portal; owner has 24 hours to approve or decline |
| Owner declines | Coordinator documents, notes on board, proceeds without that item, flags for leasing team |
| Emergency safety item (e.g., exposed wiring, gas leak) | Coordinator approves regardless of threshold, notifies owner immediately after |

No work beyond original scope begins until approval is documented in the system.

### Part 2: The Make Ready Board, 420 Doors
---
Board Stages (Left to Right)
1 Scope Approved then 2 Work Orders Created then 3 Scheduled and Access Set then 4 Work in Progress then 5 Cleaning in Progress then 6 Pre-Final Review then 7 Final Inspection Scheduled then 8 Final Inspection (Pass / Fail) then 9 Punch List / Rework (loops back to Final Inspection on completion) then 10 Photography Scheduled then 11 Make Ready Complete. Side exit: 12 Make Ready Cancelled.
#### Board Columns (Per Card / Unit)

| Column | What It Holds |
|---|---|
| Unit Address | Full address + unit # |
| Property Class | B / C / D |
| Owner Name | Linked to owner record |
| Coordinator Assigned | Remote coordinator name |
| Tech Assigned | In-house tech name |
| Vendor(s) Assigned | Vendor name(s) per trade |
| Scope Summary | Brief: paint, clean, carpet, etc. |
| Scope Approved By | Auto / Owner name + date |
| Work Order Count | # open / # closed |
| Scheduled Start Date | Date work begins |
| Target Completion Date | Based on class benchmark |
| Actual Completion Date | Filled on close |
| Days in Stage | Auto-calculated |
| Days Since Scope Approved | Auto-calculated (master clock) |
| Status | On Track / At Risk / Overdue |
| Inspection Result | Pass / Fail / Pending |
| Punch List Items | # open punch list items |
| Scope Change Flag | Yes/No + approval status |
| Photo Ready | Yes / No |
| Last Coordinator Note | Free text, date-stamped |
| Owner Last Notified | Date + method |

#### Status Values and Class-Based Time Targets
Class B, Target: 5 to 7 Days Total

| Status | Trigger |
|---|---|
| On Track | Day 1 to 5, progressing normally |
| At Risk | Day 6, not yet in Final Inspection |
| Overdue | Day 8+, not complete |

Class C, Target: 7 to 10 Days Total

| Status | Trigger |
|---|---|
| On Track | Day 1 to 7 |
| At Risk | Day 8 to 9, not yet in Final Inspection |
| Overdue | Day 11+, not complete |

Class D, Target: 10 to 14 Days Total

| Status | Trigger |
|---|---|
| On Track | Day 1 to 10 |
| At Risk | Day 11 to 13, not yet in Final Inspection |
| Overdue | Day 15+, not complete |

Master clock: starts the moment the card enters Stage 1 (Scope Approved). Punch list days count. Scope change approval wait time counts.
#### Automations: Reminders and Nudges

| Trigger | Action | Recipient |
|---|---|---|
| Work order assigned, no start confirmation in 4 hours | SMS + email nudge | Tech / Vendor |
| Card in "Work in Progress" for 50% of benchmark with no photo upload | Nudge: "Upload progress photos" | Tech / Vendor |
| Card in "Work in Progress" for 75% of benchmark with no completion | Nudge: "Completion deadline approaching" | Tech / Vendor + Coordinator |
| Card in "Cleaning in Progress" for 24 hours with no update | Nudge to cleaning vendor | Vendor + Coordinator |
| Card in "Pre-Final Review" for 4 hours with no action | Reminder to Coordinator | Coordinator |
| Final inspection not scheduled within 4 hours of pre-final passing | Reminder | Coordinator |
| Punch list items open for 24 hours (Class B/C) or 48 hours (Class D) | Nudge to responsible party | Tech / Vendor |
| Photography not scheduled within 24 hours of final pass | Reminder | Coordinator |

#### Automations: Owner Updates

| Trigger | Message | Method |
|---|---|---|
| Card enters Stage 1 (Scope Approved) | "Make ready has started. Target completion: [date]." | Email / Portal |
| Scope change discovered, over threshold | "Additional work identified. Approval needed: [scope + cost]." | Email + Portal (urgent flag) |
| Card enters Stage 4 (Work in Progress) | "Work has begun on your unit." | Email |
| Card enters Stage 8, Final Inspection Pass | "Unit passed final inspection. Photography being scheduled." | Email |
| Card enters Stage 8, Final Inspection Fail | "Unit did not pass final inspection. Punch list issued. Est. resolution: [date]." | Email |
| Card enters Stage 11 (Make Ready Complete) | "Your unit is rent-ready and photo-ready. Leasing team has been notified." | Email + Portal |
| Card turns Overdue | "Make ready is running behind schedule. Updated target: [date]. Reason: [note]." | Email |

#### Automations: Escalations

| Trigger | Escalation Action |
|---|---|
| Card turns At Risk | Coordinator receives alert; must add a note with reason and revised ETA |
| Card turns Overdue | Auto-escalates to Operations Lead / PM Director; coordinator must update within 2 hours |
| Unit fails final inspection twice | Auto-escalates to PM Director; third inspection requires director sign-off |
| Scope change approval not received from owner within 24 hours | Escalates to PM Director to decide: proceed without item or hold unit |
| Card stuck in any stage for more than 2x the stage's expected time | Escalates to Operations Lead |

#### Automations: Stage Transitions

| Condition | Auto-Action |
|---|---|
| All work orders marked complete + cleaning confirmed | Card moves: Work in Progress to Pre-Final Review |
| Pre-final review approved by Coordinator | Card moves: Pre-Final Review to Final Inspection Scheduled |
| Final inspection uploaded as PASS | Card moves: Final Inspection to Photography Scheduled |
| Final inspection uploaded as FAIL | Card moves: Final Inspection to Punch List / Rework |
| All punch list items closed + re-inspection uploaded as PASS | Card moves: Punch List / Rework to Photography Scheduled |
| Photos confirmed uploaded and approved | Card moves: Photography to Make Ready Complete |
| Make Ready Complete | Auto-notify Leasing Team; auto-update unit status in PM software to "Available" |

#### Coordinator View
Daily Board Filter: cards assigned to their portfolio, sorted Overdue first, then At Risk, then On Track.
Coordinator's Daily Checklist (Every Morning):
☐ Review all Overdue cards: add note, update ETA, contact responsible party
☐ Review all At Risk cards: confirm plan to avoid going Overdue
☐ Check all "Work in Progress" cards: confirm photos uploaded, no stuck work orders
☐ Check all "Punch List / Rework" cards: confirm items assigned and deadline set
☐ Check all "Pre-Final Review" cards: complete digital review same day
☐ Confirm any scope change approvals pending: follow up with owner if more than 12 hours
☐ Confirm photography scheduled for all units that passed final inspection
☐ Log a date-stamped note on every active card (even if just "On track, no issues")
☐ Send owner updates for any unit that changed status overnight
☐ Flag any unit approaching benchmark deadline to Operations Lead
#### Leadership View
Filters available:
All Overdue units across all 420 doors
All units by Class (B / C / D) with average days in make ready
All units with open scope change approvals
All units that have failed final inspection (once or twice)
Units by Coordinator (performance view)
Units by Vendor (vendor performance view)
Units completed this week / this month
Average days: Scope Approved to Make Ready Complete (by class, by coordinator, by vendor)
Leadership KPIs on Dashboard:

| Metric | Target |
|---|---|
| % Units completed within class benchmark | >= 85% |
| Average make ready days, Class B | <= 7 days |
| Average make ready days, Class C | <= 10 days |
| Average make ready days, Class D | <= 14 days |
| Final inspection first-pass rate | >= 80% |
| Scope change approval avg. response time | <= 24 hours |
| % Units photo-ready within 24 hours of final pass | >= 90% |

#### How This Connects To Your Existing Systems

| System | Connection |
|---|---|
| Turnover Board | Make ready card is created automatically when the Turnover Board moves to the "Work Orders Approved" stage |
| Make Ready Checklist | Final inspection checklist is the same checklist used on the board's Stage 6 and Stage 8 |
| Dispatch Decision Matrix | Used at Step 1 (Work Order Creation) to assign Tech vs. Vendor |
| Benchmarks | Drive the On Track / At Risk / Overdue status thresholds per class |
| PM Software (AppFolio/etc.) | All work orders, photos, owner communications, and inspection reports live here; the board mirrors the data |
| Leasing/Marketing Process | Triggered automatically when the card hits Stage 11 (Make Ready Complete) |
